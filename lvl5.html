LVL 5 · Station 3 · Erweiterung

    
Andere Harnesses: n8n und Claude Code

    
n8n ist ein Werkzeug, mit dem man Abläufe grafisch zusammenklickt. Es kann feste Workflows und KI-Agenten bauen und spricht MCP.
      Im Praxis-Repo startet n8n/docker-compose.yml zwei Container: n8n und denselben MCP-Server, diesmal über HTTP statt stdio.

    

      
A · fester Workflow
Formular (Klasse, Fach) → MCP-Aufruf mit fester SQL → Ergebnisseite. Kein LLM. Immer genau ein MCP-Aufruf.

      
B · Agent
Knoten AI Agent mit LLM, Verlauf und MCP Client Tool. Die Schleife steckt im Knoten, sichtbar nur in den Logs.

      
C · Workflow mit Freigabe
Schüler suchen → genau ein Treffer? → Freigabe-Seite mit Namen → add_grade. Auch ohne LLM braucht Schreiben eine Freigabe.

Claude Code ist ein Harness für die Programmierung und zugleich ein MCP-Host. Eigene Subagenten legt man genau wie im Praxis-Repo als Markdown-Dateien an
      (.claude/agents/<name>.md, siehe Station 1). Der Hauptagent delegiert dann Teilaufgaben, und jeder Subagent arbeitet in einem eigenen Kontext mit eigenen Tools.
      Freigaben stellt man über Berechtigungsmodi, Regeln (allow, ask, deny) und Hooks ein.
